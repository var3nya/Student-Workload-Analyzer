
# Student Workload & Weekly Schedule Analyzer

## Overview

Student Workload & Weekly Schedule Analyzer is a Python project that helps students keep track of their academic work.

You enter your tasks, subjects, deadlines, estimated hours and priority. The program then looks at the pending work and creates a weekly plan based on the time available.

The program also gives information about the workload, warns about upcoming deadlines, shows task status and gives a summary of overall progress.

## Features

- Add academic tasks
- Store subject, deadline, priority and estimated hours
- View all added tasks
- Calculate remaining days automatically
- Analyze workload
- Show deadline distribution
- Identify urgent and high-priority tasks
- Show early-attention warnings
- Identify weekend deadlines
- Generate a weekly study/work schedule
- Update task status
- Edit and delete tasks
- Show overall completion percentage

## Technologies Used

- Python
- Python Standard Library
- `datetime` module

## Requirements

- Python 3.x
- Command Prompt / PowerShell / Terminal

No external Python packages are required.

## How to Run

### 1. Clone the repository

Open the project folder in a terminal.

### 2. Check Python installation

Run:

```text
python --version
```

**### 3. Run the program**


Run:

```text
python main.py
```

If `python` is not recognized, use the Python executable installed on your system.

### 4. Use the menu

The program shows the following options:

1. Add Task
2. View Tasks
3. Analyze Workload & Make Weekly Plan
4. Progress & Task Management
5. Exit

Follow the instructions displayed in the terminal.
