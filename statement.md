# Project Statement

## Problem Statement

I see how students usually juggle assignments, lab work, projects and other academic tasks at once. It can become hard to choose how work to do each day and which tasks deserve more focus. This project offers a way to enter academic tasks and to generate a weekly work schedule that follows deadlines, priorities, estimated effort and the time available on each day.

## Scope

The project focuses on academic workload planning and on weekly scheduling.

- Store student tasks

- Track deadlines and priorities

- Analyze pending workload

- Identify urgent tasks

- Consider weekend deadlines

- Generate a weekly schedule

- Track task progress

- Show completion percentage

## Target Users

The main target users are students who need to manage many academic tasks within a week. The system can be useful, for college students and other learners who want a way to organize their workload.

## High-Level Features

1. Task. Storage

2. Deadline tracking

3. Workload analysis

4. Weekly schedule generation

5. Task status management

6. Progress tracking

7. Task. Deletion
